## Как использовать

### Компиляция и запуск

```bash
# Компиляция всех Java файлов
javac *.java

# Запуск приложения
java Main

Инструкция для пользователя

Как пользоваться сервисом:

1. Создание пользователя:
   · При первом запуске создайте нового пользователя
   · Сохраните ваш UUID для последующих входов
2. Создание короткой ссылки:
   · Введите длинный URL
   · Получите уникальный короткий код
   · Каждая ссылка имеет лимит 10 переходов и время жизни 24 часа
3. Переход по ссылке:
   · Введите короткий код
   · Система автоматически откроет браузер с оригинальным URL
   · При исчерпании лимита или истечении срока получите уведомление
4. Управление ссылками:
   · Просматривайте все ваши ссылки
   · Удаляйте ненужные ссылки
   · Все действия доступны только создателю ссылки
